# healthcare-billing-analysis
An Excel-based data analysis project that explores healthcare billing patterns, identifies cost variations across medical conditions, and presents actionable insights through data visualization and reporting.

## Overview

This project is part of my data analytics learning journey. I used Microsoft Excel to analyze a healthcare billing dataset and explore how billing amounts vary across different patients and medical conditions. The project helped me practice data analysis, data visualization, and presenting insights in a clear way.

## Problem Statement

The goal of this project was to understand why patients with similar medical conditions may have different billing amounts. I analyzed the data to identify patterns and summarize my findings.

## Objectives

* Explore the healthcare billing dataset.
* Analyze billing amounts across different medical conditions.
* Create charts and summaries using Excel.
* Present the findings in a professional report.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Functions

## Files

* **Healthcare Dataset.xlsx** – Dataset used for the analysis.
* **Healthcare Billing Analysis Report.pdf** – Project report with findings and insights.
